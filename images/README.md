# COVID-19 Trend Analysis & Case Forecasting

## 📌 Project Overview

This project analyzes COVID-19 data to identify trends in cases and deaths,
perform SQL-based analysis, and compare forecasting models.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL / SQLite
- Excel
- Scikit-learn
- Statsmodels

## 📂 Project Workflow

1. Data Loading & Validation
2. Data Cleaning
3. SQL Analysis
4. Exploratory Data Analysis (EDA)
5. Vaccination vs Death Analysis
6. ARIMA Forecasting
7. Random Forest Forecasting
8. Excel Report

## 📊 Analysis Performed

- COVID-19 case and death trends
- Top 10 countries by total cases
- India monthly cases
- 7-day rolling average
- Peak COVID-19 days
- Continent-wise analysis
- Vaccination vs deaths
- ARIMA forecasting
- Random Forest forecasting

## 🤖 Model Results

### ARIMA
- RMSE: 2303.7
- MAPE: 59.5%

### Random Forest
- RMSE: 196.3
- MAPE: 7.1%

### Baseline
- RMSE: 242.8
- MAPE: 8.8%

Random Forest performed better than the baseline on the test data.
